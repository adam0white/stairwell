Requests 3, 5 and 6 remain open. No new rule edition or save migration accompanies

Review target for the three skipped adoptions: 2026-11-03.

1. **Source trust has no public setter and three trust stores are not linked.** The game seeds Rıza's notebook and each resident's first impression of the new kapıcı by writing `memory.sourceTrust` directly (`seedWord` in `src/sim/people.ts`). Relationship trust (`trustOf`), voice trust and source trust are separate stores, and nothing documents which one `perceive` uses for testimony (it is source trust, confirmed in the source). Proposal: `seedSourceTrust(p, sourceId, t)` for setup, and one paragraph in the docs naming the three stores and what moves each.
2. **Being caught in contradictory testimony has no HF path.** When two residents compare notes and find the kapıcı told them opposite things, the game writes a `kapici:dishonest` belief and multiplies source trust by 0.75 itself. `confirm` only recalibrates against a revealed truth, not against a contradiction between two sources. Proposal: `contradicted(p, sourceId, prop, at)` that lowers source trust by a documented rule.
3. **Reputation from testimony uses only the default trait table.** `perceive` applies reputation for default traits; a host trait (`nosy`) needs a manual `applyReputationBelief` with the host table. Proposal: a trait table per person or per `perceive` call.
4. **Beliefs keep no provenance chain.** `belief.sources` keeps the last value per source, so the game cannot ask "who first said this". The game keeps its own ledger of what the kapıcı told whom (`RState.told`) to decide whether word gets back. Proposal: optional `origin` on a claim, carried by `converse`.
5. **A subject never hears what is said about them.** `converse` skips claims whose subject is the listener, which is right for politeness, but the game needs "word gets back": a friend of the subject tells them. The game models it as a host rule. Proposal: a `converse` option to pass on claims about the listener when the speaker's affection for the listener is high and the claim is unfavourable (loyal warning).
6. **One relay threshold for everyone.** `converse` passes on beliefs with credence at least 0.7 or at most 0.3. A talkative person passes on what they half believe; a careful one only what they are sure of. Proposal: derive the threshold from extraversion or honesty, or accept it per call.
7. **No public way to seed a belief.** The game pushes belief records directly (`seedBelief`). Proposal: `seedBelief(p, prop, value, credence, at, source?)`.
8. **Note, not a bug: people die without food and water.** A host that runs residents for a week must feed them (the game adds meals at home and the kapıcı's lunch). One line in the docs would save the next game a confusing Sunday when everyone is "dead" and cannot vote.
